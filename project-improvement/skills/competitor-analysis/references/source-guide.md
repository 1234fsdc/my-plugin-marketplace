# 来源与研究边界

## 研究前

- 写清研究问题、目标用户、地区、设备、研究日期和要支持的决定。
- 优先使用用户提供的竞品名称和链接；自动发现时说明选择逻辑。
- 先查官方来源，再用第三方和用户反馈补充；不要把搜索摘要当作最终证据。

## 研究中

- 每个竞品至少核验官网/产品页和定价或套餐信息（若公开）。
- 需要判断流程时，沿一个代表性任务走到结果；不能访问的步骤写明阻塞原因。
- 价格、功能、模型、套餐、客户数量和市场状态都要带日期。
- 评测和社区反馈要保留样本数、时间、地区和可能的商业偏差。
- 公开招聘可以作为产品方向信号，但不能直接证明已发布功能。
- 对市场份额、营收、下载量、用户数量等数字，优先使用原始来源；不同口径不能相加或互相替代。

## 不允许

- 不绕过登录、付费墙、验证码、限流、反爬、权限或技术保护。
- 不使用私人账号、私密社群、泄露资料或未授权录屏。
- 不把“没有看到”写成“没有”。
- 不生成没有来源的市场份额、评分、能力分数或用户规模。
- 不把竞品营销文案改写成已验证的产品质量。
- 不为了让报告完整而补齐不存在的证据。

## 研究结束

报告必须标注：

- 研究日期和覆盖范围。
- 已访问来源与未访问来源。
- 关键结论的证据状态。
- 样本限制、访问限制和待验证问题。
- 哪些建议是事实驱动，哪些是分析推断。
